# Flight Deck 0DTE

Tablero de lectura SPX / SPY / QQQ 0DTE. Sitio estático para GitHub Pages en 0dte.katapunta.com.

- `index.html`: el tablero (se genera con `tools/build.py` a partir del diseño).
- `data.json`: lecturas del día (velas 5m, lecturas cada 15 min, perfil por strike). La página lo recarga cada minuto.

Herramienta de lectura de mercado. No es recomendación de inversión.
